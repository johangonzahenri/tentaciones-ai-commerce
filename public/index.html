🌐 Límites de Exposición y Seguridad

Esta aplicación opera bajo el Multiclient Experience Contract (ITentacionesExperienceService). En modo PUBLIC_DEMO, la ejecución está completamente aislada:

  • 🔒 Zero Runtime Secrets: Ninguna API key ni token de producción en el bundle cliente.
  • 🛡️ Zero Core Platform Exposure: Los kernels de orquestación, gobernanza y ontología permanecen en repositorios privados.
  • ⚡ Fail-Closed Gatekeeper: Detección instantánea de tokens reales o URLs internas con bloqueo preventivo.
  • 📱 Multiclient Ready: Soporte desacoplado para Storefront Web, Mobile Apps y Kioskos.
